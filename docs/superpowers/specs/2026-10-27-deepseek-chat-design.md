# DeepSeek 单模型聊天

用户已选择先实现一个模型并授权开始。保留现有站点，以 `/en/tools/ai-chat`、`/zh/tools/ai-chat` 提供通用聊天。使用 DeepSeek 官方 API，由服务端读取密钥；不增加 SDK。英文优先，中英文界面完整。

选项：独立建站会重复账户和导航；仅做场景工具限制通用使用；采用同站通用聊天，后续可共用后端增加场景入口。此次不做图片跳舞、多模型、支付、联网搜索或文件上传。

支持连续上下文、流式回答、停止、失败后重试、复制、新建对话、移动端。会话只保留当前页面内存；请求内容会发送给 DeepSeek，页面明确提示。输出当作纯文本展示，不执行 HTML。

复用 Supabase 身份校验，调用前必须登录。服务端固定 API 地址，限制请求体、轮次数、单条及总长度、输出 token、调用频率；不信任客户端角色、模型或密钥。上游错误映射为安全错误码，处理中断、超时、空回答及流中错误。未配置密钥时明确提示未开放。

限制：进程内限流只作为基础保护，多实例上线需共享限流及持久化额度。不会自动读取或回显密钥，不调用真实付费接口作自动测试。

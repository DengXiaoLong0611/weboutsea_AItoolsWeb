# 百炼图片 API 配置与本地测试 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan inline.

**Goal:** 只接入用户暂定的阿里云百炼，准备配置、复用的服务端调用代码与三组本地效果测试入口。
**Architecture:** 原生 fetch 调用同步多模态图像编辑接口；模型和地域地址通过环境变量设置，不建立多平台框架、不新增 SDK。测试命令默认只预览，--run 才请求并保存图片。
**Tech Stack:** Node.js 22、TypeScript、node:test、Next.js 现有环境变量加载。
**Spec:** 用户本轮指定仅百炼配置代码，延续前文三组效果测试；暂不涉及网页交互或开放公共扣费接口。

## Global Constraints
- 保留现有 Supabase 与 OpenAI 配置，不读取或输出任何密钥值。
- 只允许阿里云官方 HTTPS API 地址；模型默认 qwen-image-2.1-pro，可配置。
- 原照与风格图以 Base64 直接传输，不强迫上传公开图床。
- 每组一张，失败不自动重试，避免不明确的重复扣费。
- 本轮无新密钥也能运行离线校验；真实生成须有百炼凭据与账户可用额度。

## Review Focus
- 缺密钥或地址须在发起请求前提示；不得泄露密钥。
- 401/429/服务端业务报错与非 JSON 返回须可理解且不自动重试。
- 超时和成功无图片须报告失败。
- 非法地址、图片格式和过大输入须本地拒绝。
- 不覆盖旧测试图；默认测试命令不联网。

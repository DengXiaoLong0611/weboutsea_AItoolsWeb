# 双语 URL 实现计划

**Goal:** 首页和目录提供 `/en`、`/zh`，HTML 语言与内容一致。

**Design:** 用户已选择浏览器语言方案。访问 `/` 时优先读取有效语言 Cookie，再按 Accept-Language 权重选择语言；首选中文选 zh，其余回退 en。直接语言 URL 始终优先。手动切换保存一年 Cookie，保留查询参数与锚点。语言页面使用服务端 HTML，并提供语言替代链接元数据。

**Approaches:** 固定英文默认简单但忽略中文偏好；IP 判断容易受 VPN 影响且增加依赖；采用用户选定的浏览器语言方案。

**Architecture:** 语言协商纯函数、根路径 proxy 重定向、带语言的根布局与共享首页组件。既有认证和静态工具地址保持，现有中文认证界面使用独立中文根布局。

**Tech Stack:** Next.js App Router、TypeScript、Node test runner。

# 工具目录与宠物照片 Implementation Plan

**Goal:** 保留 Showcase，将 Minimal 改成门户式工具目录，融合同站宠物照片编辑器。

**Architecture:** 独立目录组件复用站点工具数据；原生 HTML/Canvas 编辑器作为同源静态工具接入 Next.js，保留源项目。当前没有 AI 请求或密钥。

**Tech Stack:** Next.js、React、TypeScript、CSS、原生 JavaScript/Canvas。

## 用户确认的范围

- Minimal 使用白底、紧凑导航、多列平铺；Showcase 保持原风格。
- Dandan Studio 项目更名为“宠物照片”，可从工具站直接使用。
- 本轮先融合；AI 接口选择和接入后续进行。
- 保留现有 QQ 联系邮箱；原工具目录不修改。

## Review Focus

1. 搜索无匹配时给出清空入口，分类与搜索同时生效。
2. 待接入工具没有伪造的可点击使用入口。

4. 用户上传照片留在浏览器，PNG 可下载，源照片清晰度提示保留。
5. 手机无水平溢出；返回目录保留 Minimal 模式。

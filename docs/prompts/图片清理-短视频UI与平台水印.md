# 净图助手｜短视频截图清理

保存日期：2026-10-25
适用工具：imagegen 等支持上传图片进行编辑的图像模型。
版本：通用复用版，由宠物照片示例清理需求整理，并非某一次调用提示词的逐字记录。

## 使用方法

上传需要清理的原图，再复制下方提示词。普通照片可删除“右上角原照片”和“手绘风格”相关要求。建议保留原图，将结果另存为清理版。

## 可复制提示词

```text
请编辑我上传的图片，清除短视频平台叠加的界面元素，让图片恢复成干净、完整的作品展示图。

需要移除：
1. 中间半透明的播放按钮。
2. 右侧头像、用户名、关注加号，以及点赞、评论、收藏、分享按钮和数字。
3. 顶部和底部的平台导航、标题文案、话题标签、音乐信息。
4. 平台 Logo、平台水印、账号 ID 等叠加内容。

修复要求：
- 根据周围画面自然补全被遮挡区域，保持背景、纹理、色彩和笔触一致。
- 保留原有主体、构图、人物表情、宠物外貌，以及手绘画面的风格。
- 如果右上角有用于对照的原照片，请保留其位置、边框和内容；只清除覆盖在上面的平台界面元素。
- 不要添加新文字、Logo、水印或其他装饰。
- 尽量保持原始细节，不要重新设计画面，也不要随意改变人物或宠物。
- 输出清晰、自然、没有明显涂抹痕迹的完整图片。
```

## 使用备注

- AI 会补画被遮挡区域，细节无法保证完全还原；检查脸部、手部、宠物花纹和右上角对照照片。
- 用于有权编辑和使用的素材；作者签名与版权标记应保留。
- 网站展示应标为风格参考或 AI 修复示例，不应当作尚未接入的 API 实测结果。

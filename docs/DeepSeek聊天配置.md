# DeepSeek 聊天配置

入口：`/en/tools/ai-chat`、`/zh/tools/ai-chat`，也可从首页工具目录打开 AI Chat。

## 本地配置

在 `ai-tools-site/.env.local` 中添加以下服务端变量（该文件不提交）：

```dotenv
DEEPSEEK_API_KEY=在这里填写你的密钥
DEEPSEEK_MODEL=deepseek-flash
```

密钥从 DeepSeek 控制台获取，不要发到聊天窗口，不要使用 `NEXT_PUBLIC_` 前缀。设置后重启 `npm run dev`。API 地址固定为 `https://api.deepseek.com/chat/completions`，不接受浏览器传入密钥或模型。

2026-10-27 按官方文档默认使用 `deepseek-flash`，关闭思考模式，以优先保证普通聊天响应速度；也可配置当前账户可用的模型名。参考：[API 文档](https://api-docs.deepseek.com/api/create-chat-completion/)。

账户验证复用现有 Supabase，相关环境变量及回调设置见 [Supabase登录配置](./Supabase登录配置.md)。用户发送消息时如果未登录，会看到登录入口；登录在新标签页完成后回到聊天页重试，不用丢弃问题。原登录/账户页目前为中文。

## Vercel

在对应项目的 Environment Variables 中添加 `DEEPSEEK_API_KEY` 和 `DEEPSEEK_MODEL`，确认 Supabase 配置及 `NEXT_PUBLIC_SITE_URL` 是正式域名，然后重新部署。服务端函数需要支持流式响应及至少 90 秒运行时间（路由 `maxDuration=120`，实际额度受平台套餐限制）。本站未在此任务自动部署。

## 当前能力与限制

- 中英文界面、连续上下文、流式回复、停止生成、失败重试、复制回复、新建对话。
- 输出为纯文本，不渲染 HTML；不支持附件、联网搜索或多模型选择。
- 对话仅保存在当前标签页内存，不写入数据库或 localStorage。刷新、切换语言或离开后不保留；清空有确认。
- 生成时会将当前对话上下文发送至 DeepSeek。不代表服务商不记录请求；请按服务商条款处理敏感信息。本站代码不记录消息或密钥。
- 必须通过 Supabase `getUser` 验证。请求需同源；每个服务实例每用户最多 15 次/分钟，不自动重试付费请求。
- 请求体最多 160 KiB；最多 31 条消息，单条最多 8,000 字符，总上下文最多 24,000 字符；最多生成 4,096 tokens；90 秒后中止。
- 达到长度上限、新会话、重试与保留部分回复均提供明确操作；重试会重新调用 API 并可能计费。超出消息长度的回答可复制，但需要新建对话。
- **生产扩展前需增加共享限流及持久化用户额度**：当前进程内限流会随重启重置，多实例之间不共享，不能作为收费产品的额度系统。
- 目录暂标为“内测”，不是“已上线”。真实认证与模型调用验收后再更新状态。

## 验收步骤

1. 没有配置密钥时显示界面预览提示，不产生生成请求。
2. 配置密钥并重启；未登录发送消息显示登录提示。
3. 登录后发送短问题，确认真实回复逐步出现。
4. 提问引用上一轮内容，确认上下文有效。
5. 测试停止、重试、复制和清空；手机布局不横向溢出。
6. 核对控制台用量及余额；不要将真实回答测试与离线模拟测试混淆。

自动测试使用模拟上游响应，不会消耗 DeepSeek 余额，也不能证明真实密钥、余额或线上服务已可用。

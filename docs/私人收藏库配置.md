# 私人 API 与提示词收藏库

入口：`/admin/api-library`。未登录跳转登录页；非管理员返回 404。

在 Vercel 项目 Settings → Environment Variables 添加服务端变量 `PRIVATE_LIBRARY_ADMIN_EMAILS`，值为管理员登录邮箱，多个用英文逗号分隔。不要加 NEXT_PUBLIC 前缀。修改后重新部署。

需同时完成 Supabase 登录配置。变量为空时拒绝所有用户，不会把首个注册用户自动设为管理员。管理员登录后，在“我的账户”页面可看到收藏库入口。

已收录：**净图助手｜短视频截图清理**提示词，以及 fal.ai、Black Forest Labs、OpenAI API 官网候选；供应商均未接入、未实测。无密钥存储功能。

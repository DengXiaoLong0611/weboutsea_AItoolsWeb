## 打包应用

deployment 目录包含 langgraph.json、task_maistro.py、configuration.py、requirements.txt 和 Compose 示例。JSON 将 task_maistro 映射到图实现，依赖清单和环境配置共同构成服务包。

## 构建与启动服务

上游流程安装 langgraph-cli，在 module-6/deployment 中执行 langgraph build -t my-image。将 docker-compose-example.yml 复制为 docker-compose.yml，将 image 字段设置为构建的镜像名（默认 my-image），并私下设置所需服务密钥，再执行 docker compose up。需要先安装并启动 Docker。

## 服务端、Redis 与 PostgreSQL

示例启动 API、Redis 和 PostgreSQL 三个容器，通过 8123 端口提供 API 与 /docs。这个 Python 图执行服务与 Vercel 上的静态教程页面是两件事：发布网站不会自动部署它。复现实验前应核对当前 LangGraph 的许可和 CLI 要求。

```sh
cd module-6/deployment
cp docker-compose-example.yml docker-compose.yml
langgraph build -t my-image
# Configure the image field and credentials locally before starting services.
docker compose up
```

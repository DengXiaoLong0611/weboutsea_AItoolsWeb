## Run、Thread 与 Store

通过 langgraph_sdk.get_client 连接服务 URL。Run 是一次执行，Thread 组织会话检查点，Store 保存跨会话记忆。若在 LangGraph 中组合远程图，也可使用 RemoteGraph。

## 后台与流式运行

runs.create 启动后台执行，runs.get 查询状态，runs.join 等待结束。等待某个 run 并不会全局禁止其他客户端发起任务。快照使用 messages-tuple 流式事件，事件名称和数据结构需要与实际服务及 SDK 版本匹配。

## 检查、分叉与共享记忆

修改检查点前先读取 thread 状态与历史。复用 message ID 会通过 reducer 替换原消息，而非追加。部署版的 ToDo namespace 是 (todo, todo_category, user_id)，不同于 Module 5 的简化版本；默认 category 为 general。

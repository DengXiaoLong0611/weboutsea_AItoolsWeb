## Runs, threads and stores

Use langgraph_sdk.get_client with the server URL. A run is one execution, a thread groups conversation checkpoints, and the store holds cross-thread memories. RemoteGraph is another interface when composing with LangGraph itself.

## Background and streaming runs

runs.create starts a background execution; runs.get reads its status and runs.join waits for completion. Joining one run does not globally serialize other clients. The snapshot streams message events with messages-tuple; event names and payload shapes must match your installed server and SDK versions.

## Inspect, fork and share memory

Read thread state and history before editing a checkpoint. Reusing a message ID replaces that message through the reducer rather than appending. The deployed graph’s ToDo namespace is (todo, todo_category, user_id), unlike the simpler Module 5 example; the default category is general.

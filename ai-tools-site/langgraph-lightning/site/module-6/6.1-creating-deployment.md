## Package the application

The deployment folder contains langgraph.json, task_maistro.py, configuration.py, requirements.txt and a Compose example. The JSON maps task_maistro to its graph implementation; dependencies and environment settings complete the server package.

## Build and start services

The historical workflow installs langgraph-cli and runs langgraph build -t my-image from module-6/deployment. Copy docker-compose-example.yml to docker-compose.yml, set the image field (my-image by default) and the required provider credentials privately, then run docker compose up. Docker must already be available.

## Server, Redis and PostgreSQL

The example launches API, Redis and PostgreSQL containers. Port 8123 exposes the API and /docs. Graph execution is separate from hosting these static lessons on Vercel: publishing the website does not deploy this Python service. Check current LangGraph licensing and CLI requirements before reproducing this historical setup.

```sh
cd module-6/deployment
cp docker-compose-example.yml docker-compose.yml
langgraph build -t my-image
# Configure the image field and credentials locally before starting services.
docker compose up
```

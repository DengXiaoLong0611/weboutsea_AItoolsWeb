## 🎯 Core Concept

### What is LangChain?

LangChain is a development framework for building **LLM (Large Language Model) applications**. It provides:

- **Modular components**: Chat Models, Prompts, Tools, Memory, etc.
- **Standardized Interface**: Unified API, supports multiple LLM providers
- **Chain combination**: combine multiple components into complex workflows

### What is LangGraph?

LangGraph is the **graph orchestration framework** in the LangChain ecosystem, specifically used to build Agent and multi-Agent applications. Its core advantages:

1. **Cycles Support (Cycles)**: Supports workflows with cycles, not just DAGs (Directed Acyclic Graphs)
2. **Precise control (Controllability)**: can accurately control the execution process of the Agent
3. **Persistence**: Supports saving and restoring state

### Why do you need LangGraph?

There are problems with the traditional Agent framework:
- ❌ Lack of control over execution process
- ❌ Difficulty handling complex decision-making logic
- ❌ Unable to reliably put into production environment

LangGraph’s solution:
- ✅ Model Agent workflow as **State Chart**
- ✅ Precisely control the execution path through nodes and edges
- ✅ Supports production-level features such as manual intervention and error recovery

## 🤖 Chat Models detailed explanation

### What is Chat Model?

Chat Model is a model that accepts a message list as input and returns a chat message as output. Unlike traditional text generation models, the Chat Model understands the context and roles of the conversation.

### Core Features

```
输入：[HumanMessage, AIMessage, SystemMessage, ...]
  ↓
Chat Model (如 GPT-4)
  ↓
输出：AIMessage
```

### LangChain’s Chat Model Integration

LangChain **does not host models** but provides a unified interface that supports multiple providers:

| Providers | Model Examples | Integration Packages |
|--------|---------|--------|
| OpenAI | GPT-4, GPT-3.5 | `langchain_openai` |
| Anthropic | Claude | `langchain_anthropic` |
| Google | Gemini | `langchain_google_genai` |
| Azure | Azure OpenAI | `langchain_openai` |

**Benefits:**
- Unified API to easily switch models
- Model-independent application design
- Supports 70+ model providers

## 💻 Chat Model practice

### 1. Initialize Chat Model

```python
from langchain_openai import ChatOpenAI

# 初始化 GPT-4o
gpt4o_chat = ChatOpenAI(model="gpt-4o", temperature=0)

# 初始化 GPT-3.5（更便宜）
gpt35_chat = ChatOpenAI(model="gpt-3.5-turbo-0125", temperature=0)
```

**Detailed explanation of key parameters:**

#### `model` (model name)

```python
# GPT-4 系列 - 高质量、较贵
"gpt-4o"              # 最新优化版本
"gpt-4-turbo"         # GPT-4 Turbo

# GPT-3.5 系列 - 便宜、快速
"gpt-3.5-turbo-0125"  # GPT-3.5 最新版本
```

**How ​​to choose? **
- High quality output required → GPT-4
- Need to reduce costs → GPT-3.5
- Needs balance → GPT-4o (default for this course)

#### `temperature` (temperature parameter)

Control the **randomness** and **creativity** of your output:

```python
temperature = 0    # 确定性输出（适合事实查询、代码生成）
temperature = 0.7  # 平衡（适合对话）
temperature = 1.0  # 最大创造性（适合创意写作）
```

**Example comparison:**

```python
# Temperature = 0 (每次输出几乎相同)
"巴黎是法国的首都。"
"巴黎是法国的首都。"

# Temperature = 1.0 (每次输出不同)
"巴黎，这座浪漫之都，是法国的首都。"
"法国的首都是美丽的巴黎。"
```

### 2. Call Chat Model

#### Method 1: Using message object

```python
from langchain_core.messages import HumanMessage

# 创建消息
msg = HumanMessage(content="Hello world", name="Lance")

# 调用模型
```

**Output:**
```python
AIMessage(

    response_metadata={

        'model_name': 'gpt-4o-2024-05-13',
        'finish_reason': 'stop'

```

**LangChain knowledge point: message type**

| Message type | Function | Example |
|---------|------|------|
| `HumanMessage` | User input | User questions, instructions |
| `AIMessage` | AI reply | Model's answer |
| `SystemMessage` | System command | Set AI role and behavior |
| `FunctionMessage` | Function call result | Return value of Tool execution |

**Message object structure:**

```python

    content="Hello world",  # 消息内容
    name="Lance"            # 可选：发送者名称
)
```

```python
response = gpt4o_chat.invoke("hello world")
```

**Internal Conversion:**
```python

```

**When to use? **
- ✅ Simple one-round dialogue
- ❌ Multiple rounds of dialogue (need to keep history)

## 🎓 Summary of core knowledge points

### LangChain Core Concept

#### 1. Runnable interface

All LangChain components (Chat Models, Tools, Chains) implement the **Runnable interface**:

| Method | Function | Usage scenarios |
|------|------|---------|
| `invoke(input)` | Synchronous call | Single request |
| `stream(input)` | Streaming output | Long text generation |
| `batch(inputs)` | Batch calls | Process multiple inputs in parallel |
| `ainvoke(input)` | Asynchronous call | High concurrency scenario |

**Example:**

```python
# invoke - 等待完整响应
response = chat.invoke("Tell me a joke")

# stream - 逐 token 返回
for chunk in chat.stream("Tell me a joke"):
    print(chunk.content, end="")
```

#### 2. Messages (message system)

LangChain uses message objects instead of plain text:

```python
# ❌ 不推荐：纯文本
"What is the capital of France?"

# ✅ 推荐：消息对象
HumanMessage(content="What is the capital of France?")
```

**Advantages:**
- 📋 Keep conversation history
- 🎭 Distinguish between different roles
- 🔧 Support multi-modal (text, pictures, audio)

#### 3. Best practices for model initialization

```python
# ✅ 在应用启动时初始化一次
chat = ChatOpenAI(model="gpt-4o", temperature=0)

# ❌ 不要在循环中重复初始化
for _ in range(10):
    chat = ChatOpenAI(...)  # 性能浪费
```

### 2. Streaming output optimizes user experience

```python

    print(chunk.content, end="", flush=True)  # 逐 token 显示
```

## 📊 Cost optimization

### Token usage statistics

```python
response = chat.invoke("Hello world")

# 查看 token 使用情况
metadata = response.response_metadata['token_usage']
print(f"输入 tokens: {metadata['prompt_tokens']}")
print(f"输出 tokens: {metadata['completion_tokens']}")
print(f"总计 tokens: {metadata['total_tokens']}")
```

**Example output:**
```
输入 tokens: 9
输出 tokens: 9
总计 tokens: 18
```

### Cost estimate

| Model | Input price ($/1M tokens) | Output price ($/1M tokens) |
|------|-----------------------|-----------------------|
| GPT-4o | $5.00 | $15.00 |
| GPT-3.5 | $0.50 | $1.50 |

**Calculation example:**
```python
# GPT-4o 处理 1000 tokens 输入 + 1000 tokens 输出
cost = (1000/1000000 * 5) + (1000/1000000 * 15)
# = $0.005 + $0.015 = $0.02（2 分钱）
```

## 🎯 Practical application cases

### Case 1: Simple question and answer robot

```python
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage, AIMessage

# 初始化模型
chat = ChatOpenAI(model="gpt-4o", temperature=0.7)

# 对话历史
history = []

def chat_bot(user_input):
    # 添加用户消息
    history.append(HumanMessage(content=user_input))

    # 调用模型
    response = chat.invoke(history)

    # 添加 AI 回复到历史
    history.append(response)

    return response.content

# 使用
print(chat_bot("你好"))
print(chat_bot("我刚才说了什么？"))  # 能记住上下文
```

### Case 2: Search Enhanced Q&A (Simple RAG)

```python
from langchain_community.tools.tavily_search import TavilySearchResults
from langchain_openai import ChatOpenAI

chat = ChatOpenAI(model="gpt-4o", temperature=0)
search = TavilySearchResults(max_results=3)

def search_qa(question):
    # 1. 搜索相关信息
    search_results = search.invoke(question)
    context = "\n\n".join([doc['content'] for doc in search_results])

    # 2. 结合搜索结果生成答案
    prompt = f"""基于以下信息回答问题：

信息：
{context}

问题：{question}

答案："""

    response = chat.invoke(prompt)
    return response.content

# 使用
answer = search_qa("LangGraph 的主要优势是什么？")
print(answer)
```

### Case 3: Multi-model comparison

```python
models = {

    print(f"\n{name} 的回答：")
```

## 🔍 Frequently Asked Questions

### Q1: Why use message objects instead of strings?

**String mode:**
```python
chat.invoke("Hello")  # 简单，但丢失上下文
```

**Message object mode:**
```python
messages = [
    SystemMessage(content="你是助手"),
    HumanMessage(content="Hello")
]
chat.invoke(messages)  # 保留角色、历史
```

**Advantages:**
- 🔄 Support multiple rounds of dialogue
- 🎭 Distinguish between system/user/AI roles
- 📊 Better debugging and logging

### Q2: Is temperature=0 really sure?

**Not entirely sure! **

```python
chat = ChatOpenAI(temperature=0)

# 相同输入，99% 情况输出相同
response1 = chat.invoke("1+1=?")  # → "2"
response2 = chat.invoke("1+1=?")  # → "2"

# 但模型更新或其他因素可能导致微小差异
```

**When to use temperature=0? **
- ✅ Tasks that require consistency (testing, evaluation)
- ✅ Factual answers
- ❌ Not suitable for creative tasks

### Q3: How to choose max_results?

```python
# 搜索结果数量权衡
search = TavilySearchResults(max_results=N)
```

| max_results | Advantages | Disadvantages |
|------------|------|------|
| 1-3 | Fast, focused | Information may be missed |
| 5-10 | Comprehensive | High cost and noisy |
| 10+ | Most comprehensive | Exceeds LLM context limits |

**Recommended:**
- Easy questions: 3
- Complex Research: 5-10
- Comparative analysis: 3-5

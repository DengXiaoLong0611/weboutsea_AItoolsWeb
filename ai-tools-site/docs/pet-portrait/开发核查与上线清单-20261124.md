# 人宠肖像开发核查与上线清单

日期：2026-11-24。基于现有代码及 Pet Plus Us 考察材料，保留人宠合照为主要业务，加入仅宠物模式。未调用付费生成、发送邮件或执行真实支付。后续远程配置及迁移已执行，当前状态见 [异机开发交接](./异机开发交接-20261124.md)。

## 已接入代码

- 115 个独立风格配置：90 个人宠合照、25 个仅宠物；公共身份保真规则与独立场景组合。每个配置记录版本。全部为 draft，尚无逐项出图验收和原创缩略图，当前主要是写实摄影场景变化。
- 持久化任务：上传完成后入队，数据库原子领取，避免多个执行器重复调用生成服务。任务保存提示词、版本、模型、参数、请求信息及供应商用量。
- 重试区分：明确拒绝可有限重试；已有结果的交付失败复用供应商图片；扣费结果不明时停止自动生成，提示人工核查。重试也计入全局生成次数额度。
- 支付按目录价格校验，收据与订单明细事务落库；退款以 payment_intent 为准，重复或乱序通知不能恢复退款权限，一个订单退款不撤销其他订单。
- 私有图片、水印预览、付费下载权限；签名下载链接有效期 120 秒，退款前已签发的链接在到期前仍可能有效。
- 刷新后读取已有任务并继续查询。浏览器关闭前已经提交的任务可继续处理；后续尚未提交的预览不会自动创建。
- 付费图库可创建有效期 7 天的私密恢复链接，数据库仅存令牌哈希；新链接替换旧链接，并支持撤销。持有者能访问对应图库，属于访问凭证，应私密保存；不是邮箱身份认证。
- 删除先写入禁止恢复的标记，阻止任务和支付回调重建数据；存储删除失败会报错。保留匿名化额度计数以限制滥用，删除参考图摘要。
- 请求体实际流式限额；图片格式与尺寸校验；过期内容清理和受保护的任务补偿入口。

## 上线前必须完成

1. 在备份及测试环境验证后，按时间顺序应用 `20261123092816_pet_portraits.sql`、`20261123182823_pet_portrait_commerce.sql`、`20261123182840_expand_pet_portrait_catalog.sql`、`20261123182852_harden_pet_portrait_lifecycle.sql`。现已通过插件应用到当前关联远程项目，详见交接文件。
2. 配置 Supabase 服务端密钥、固定签名密钥、百炼图片模型和额度、Stripe 测试密钥、Webhook 签名密钥及站点地址，按 `.env.example` 设置。普通图库目前也要求模型配置可用，应一并配置。
3. 配置外部调度器：建议每分钟 POST `/api/pet-portrait/worker`，每次处理一个任务；清理入口 `/api/pet-portrait/cleanup` 使用 POST。两者携带 `Authorization: Bearer <PET_PORTRAIT_CRON_SECRET>`。按队列吞吐量调整频率，平台执行时限至少满足路由 240 秒设置。`after()` 只作快速启动，不能代替调度器。
4. 使用 Stripe 测试模式完成支付成功、取消、异步支付、重复通知、退款、跨浏览器恢复及删除后的实际联调；核查商户退款政策。当前任何正金额退款都暂停该订单全部下载，部分退款需人工处理明细分配。
5. 在真实浏览器验收移动端、上传、刷新恢复、恢复链接、失败提示、下载及删除流程。浏览器工具连接受阻，尚未完成视觉验收或线上端到端验证；HTTP 冒烟检查已通过。
6. 补齐真实客服邮箱、商户主体、隐私政策、保留期限、退款与授权使用条款。不要填虚构信息。
7. 检查构建工具报告的 Next.js 安全版本提示，核对官方公告并安排依赖修复及回归；现已升级 Next.js 与 eslint-config-next 至 16.4.6，生产依赖审计为零漏洞。

## 下一批优先完善

- 风格质量：先挑 10–15 个主推场景，用不同人脸、肤色、宠物体型和毛色验收，再扩展全库。检查身份、花纹、手部、主体数量、接触姿势和统一光影。记录通过率后才标为已验证，并配原创缩略图。
- 邮箱通知与订单找回：目前只有手动保存的恢复链接；尚无经过验证的邮箱绑定、送达重试和邮件退订体系。
- 成本与质量后台：已有供应商用量记录，尚无按实际账单计算的金额成本、转化漏斗、失败率告警及人工补偿后台。
- 防滥用：Cookie 可被清除，目前访客额度不能代表强身份；全局调用额度控制总支出，但仍需按流量补充身份、IP 限流或挑战验证。
- 输入审核：尚无人物数量识别、内容安全审核、智能裁剪；目前限定一人一宠或单宠，未支持多人家庭与多宠。
- 任务运维：增加排队时间、失败告警、供应商请求对账；调度器是补偿入口，尚未接入具有长期重试与监控能力的专用队列平台。
- 礼品、实体打印、物流、推广分佣延后。先稳定数字肖像的生成、付款、交付、退款闭环。
